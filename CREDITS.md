# Credits

## Music

The background loop (`s/music.mp3`) was generated for this game with the ElevenLabs Music model through Higgsfield.

The owner decided on 23 November 2026 to keep this track and accept the open question of whether that model's licence terms cover use in a game. A set of CC0 tracks from OpenGameArt was tried the same day and rejected because it did not fit the game.
